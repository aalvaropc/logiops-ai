# Devpost submission fields (Amazon Developer Hackathon)

A working template: the form itself is only visible when submitting, so check each row
against it. The draft text for the long fields lives outside this repository.

| Field | Content | Status |
|---|---|---|
| Project name | LogiOps AI (or another memorable name) | to decide |
| Elevator pitch | one sentence, 200 characters at most | drafted |
| Track | Alexa+ | fixed |
| Mini Challenge | AWS Builder, only if deployed on AWS | depends on the deployment |
| Description | what it does, how it was built, challenges, what's next; name the track tool (Alexa+, MCP) | drafted |
| Built with | tags; Alexa+ and MCP must appear | drafted |
| Repository | this repository, public or with the reviewers invited (`rules-verification.md` 4 and 6) | open |
| Demo video | under 3 minutes, public, English or captioned | to record |
| Testing instructions | `docs/hackathon/testing-instructions.md` | ready |
| Product Feedback | `docs/hackathon/amazon-feedback.md` (required) | ready |
| Updates since earlier work | not applicable: the project started inside the hackathon period | n/a |

Materials must be in English (or translated): README, description, video, captions,
testing instructions and the main diagrams.
